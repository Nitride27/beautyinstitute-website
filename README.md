# beautyinstitute-website

Éclat Beauty Institute marketing/enrollment site — Next.js 15 (App Router) + TypeScript + Tailwind v4 + GSAP/ScrollTrigger + Framer Motion.

## Setup

```bash
npm install
npm run dev        # http://localhost:3000
```

## Commands

```bash
npm run dev         # local dev server
npm run build       # production build
npm run lint        # eslint
npm run typecheck   # tsc --noEmit
```

See `ARCHITECTURE.md`, `DESIGN.md`, `IMPLEMENTATION_PLAN.md`, and `AGENTS.md` for structure, tokens, phases, and agent rules.
